# 🎛️ FinesDeck

Лёгкий программный аналог Stream Deck для стримеров и геймеров для Windows. Написан на **AutoHotkey v1.1** с использованием **HTML/CSS**.

## ✨ Возможности 9 кнопок (`Numpad 1–9`)
* **`NUM 1` — Микрофон MUTE/UNMUTE:** глобально отключает и включает микрофон во всей системе Windows с красной индикацией.
* **`NUM 2` — Звук ПК MUTE:** мгновенно глушит весь системный звук компьютера.
* **`NUM 3` — Пауза / Плей:** управляет воспроизведением музыки и видео ДАЖЕ в фоновой вкладке браузера или Telegram.
* **`NUM 4` — Рандомайзер (1–100):** анимированная рулетка случайного числа прямо на кнопке с автоматическим копированием результата в буфер обмена.
* **`NUM 5` — Скриншот области:** мгновенно вызывает ножницы Windows (`Win + Shift + S`).
* **`NUM 6` — Очистка RAM:** освобождает оперативную память в один клик без открытия лишних окон.
* **`NUM 7` — Свернуть все окна:** быстрый выход на рабочий стол.
* **`NUM 8` — Таймер 05:00:** запускает обратный отсчёт прямо на плитке.
* **`NUM 9` — Не беспокоить (Focus Assist):** блокирует всплывающие баннеры и звуки уведомлений Windows во время стрима или катки.

## ⚙️ Кастомизация и управление
* **Своё название панели:** нажми на иконку шестерёнки **`⚙`** в углу окна, чтобы вписать свой никнейм (настройка автоматически сохраняется в `Документы\Fines Deck`).
* **`Alt + D`** — мгновенно скрыть или показать панель поверх любых окон.
* Свободное перемещение по экрану зажатием ЛКМ за верхнюю панель.

## 🚀 Как запустить
1. Скачай и установи [AutoHotkey v1.1](https://autohotkey.com).
2. Скачай файл `FinesDeck.ahk` из этого репозитория и запусти его двойным кликом.
3. Закрыть программу получится только через Tray или Диспечер Задач
